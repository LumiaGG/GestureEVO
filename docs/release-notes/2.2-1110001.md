### 新增与优化

- 外部拖放面板新增左侧、右侧布局，可设置最大列数、高度上限及排布优先级；支持上下悬停翻页、翻页进度提示，并在短屏或大字体下自动滚动。
- 外部拖放的工具按钮与搜索引擎可独立开启；仅显示引擎时，没有匹配内容的引擎则不显示空面板。
- 拖放内容悬停搜索引擎达到长按时限后振动提示，松手以小窗打开；普通搜索页与分词页的引擎长按也增加振动反馈。
- 双模式搜索引擎新增“优先文字 / 优先图片 / 每次询问”，统一用于屏幕识别、搜索页和外部拖放；只有一种内容时直接采用对应模式。

### 修复

- 修复图片搜索目标应用被冻结时无法启动或出现异常的问题，先解冻目标应用再授权并启动搜索。
- 修复系统深浅主题切换后，外部拖放面板、屏幕搜索面板及 Pin 内容卡部分配色残留的问题。
- 修复图片搜索完成回调重复执行、识别图片引用未释放，以及外部拖放搜索页面重建时待选择的搜索丢失或重复启动的问题。

### 兼容性

- 外部拖放面板默认仍位于底部，侧边布局按需开启，无需数据库迁移。
- 双模式引擎在同时包含文字与图片时默认改为“优先文字”；如需沿用此前优先搜图的行为，请在对应引擎中选择“优先图片”。该偏好随配置保存及导入导出保留。
