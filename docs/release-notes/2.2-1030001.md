### 新增

- 新增外部拖放接收悬浮窗：从其他应用拖动文字或图片时，可拖入对应区域加入 Pin 池、固定为 Pin 图、进入分词或直接搜索。
- 新增“临时禁用手势”动作，支持自定义暂停时长，仅暂停执行该动作的触发器，并可通过通知延长暂停或提前恢复。
- 指针新增圆点、小圆点、圆环、十字准星和箭头五种形状，支持调整大小及开启点击缩放反馈。
- 屏幕内容新增“悬浮窗边缘滑动返回”开关，关闭后可从左右边缘正常开始框选。

### 优化

- 外部拖放搜索复用已有搜索引擎及显示配置，根据文字或图片类型筛选可用引擎，支持拖动至左右边缘停留翻页。
- “功能设置 → 分享设置”新增外部拖放悬浮窗和搜索引擎显示开关，均默认开启，修改后自动保存，无需重启服务。

### 构建与维护

- PR 创建和更新不再自动触发检查；支持按需运行轻量检查或完整 Android 验证，减少重复编译。
