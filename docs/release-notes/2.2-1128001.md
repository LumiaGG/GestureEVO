### 新增与优化

- 动作编辑新增「执行延迟」，短动作和长动作可分别设置。支持拖动滑块或直接输入毫秒数，范围为 0–2,000 毫秒，设为 0 时立即执行。
- 指针新增「框选后二次确认」，默认关闭。开启「悬停指针后进入框选模式」后即可设置。拖出选框并松手后，可先调整选区，再确认进入分词页面。悬停后直接松手仍可选取当前界面元素。
- 屏幕内容新增「框选后高亮文本」，默认开启，同时适用于屏幕内容和指针的二次确认界面。关闭后，预览阶段会跳过文本检测。指针进入框选时也改为按需加载 OCR 引擎。

### 修复

- 修复部分旧版 Android 上，快速搜索在输入为空时可能无法读取并显示剪贴板内容的问题。
