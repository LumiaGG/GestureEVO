### 新增与优化

- 快速搜索支持已导入的动态快捷方式，可按快捷方式名称、所属应用名称、全拼或拼音首字母查找。结果支持点按启动、长按小窗打开，也可置顶或隐藏。「设置 → 搜索 → 功能设置」中的「搜索动态快捷方式」默认开启。

### 修复

- 修复从 Pin 图或 Pin 池拖动发送时操作面板固定在底部、可能遮挡系统界面的问题。面板现在跟随「分享与拖放」中的「拖放悬浮窗位置」设置，悬停在「取消」或「重新 Pin」目标上时显示对应的预览图标。
